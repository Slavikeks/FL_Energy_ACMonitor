Новая группа

При 0 текущий кондиционер сначала выключается, затем включается резервный. Ротация сохраняется.

В AUTO-группе исправные участники, которые сейчас не нужны для нагрузки, остаются включены в режиме вентиляции с заданной скоростью. При необходимости автоматика переводит резерв в рабочий режим группы.

Параметр M ограничивает число активных устройств; кондиционеры в резервной вентиляции в N и M не входят. При отключённой опции резервы выключаются. Для ротации без одновременной работы активных кондиционеров задайте перекрытие 0.

Справка

Устройство, протоколы и мониторинг по SNMP

Об устройстве

FL Energy AC Monitor — сетевой шлюз для наблюдения за кондиционерами Midea и управления ими. Контроллер WT32-ETH01 опрашивает кондиционеры по Midea XYE: это протокол производителя, работающий по полудуплексной шине RS‑485 на скорости 4800 бод, формат 8N1.

Для мониторинга по сети доступны SNMPv2c (опрос только для чтения и отправка уведомлений) и исходящие публикации MQTT. SNMPv2c не шифрует community и данные, поэтому используйте его в доверенной локальной сети.

XYE — протокол связи с кондиционерами. SNMP и MQTT передают состояние устройства по Ethernet. Это разные уровни связи.

С чего начать

В SNMP-менеджере выполните GET или WALK с настроенной read-only community. Агент слушает UDP/161. Для trap-уведомлений укажите адрес приёмника и UDP-порт в Settings (обычно 162).

Все собственные OID устройства начинаются с .1.3.6.1.4.1.67213 — зарегистрированного номера предприятия FLINK LLC.

Как работает автоматика и группы кондиционеров

Группа объединяет несколько кондиционеров и задаёт правила их совместной работы. У каждого кондиционера остаются свои адрес и имя. В автоматическом режиме контроллер управляет группой целиком.

Ручной режим группы

В ручном режиме группа служит только для визуального объединения кондиционеров. Управляйте каждым кондиционером отдельно на его карточке.

Автоматический режим группы

Если автоматическое управление включено в системных настройках, контроллер поддерживает заданное число работающих кондиционеров, выбирает резерв при отказе, следит за температурой и при необходимости возвращает настройки к заданным для группы.

N — сколько кондиционеров контроллер старается держать работающими в обычном режиме.
M — верхний предел числа одновременно работающих кондиционеров.

Например, при N=1 и M=2 обычно работает один кондиционер. Второй может включиться, если температура T1 в группе остаётся выше порога заданное время, либо если понадобится заменить отказавший кондиционер. Когда температура опустится ниже порога восстановления и продержится там заданное время, контроллер вернётся к N. Если M=N, второй кондиционер не включится для усиления охлаждения по температуре.

Для температурных порогов используется самое высокое свежее показание T1 среди кондиционеров группы. Задержки помогают не реагировать на кратковременные скачки температуры.

Резерв и отказ кондиционера

Если работающих исправных кондиционеров становится меньше N, контроллер старается запустить доступный резерв. Краткий пропуск ответа ещё не считается отказом: контроллер ждёт, пока кондиционер будет объявлен офлайн после нескольких неудачных опросов. Это снижает риск лишнего одновременного запуска.

Ротация

Ротация по расписанию меняет кондиционер, который несёт основную нагрузку.

При установленной задержке передачи контроллер сначала запускает и проверяет резерв, затем ждёт заданный интервал и выводит прежний кондиционер из рабочего режима. Для такого перекрытия нужен свободный слот в M. При задержке 0 старый кондиционер выводится из рабочего режима перед запуском нового, поэтому возможна короткая пауза. Если включена вентиляция резервных, прежний кондиционер перейдёт в режим вентиляции вместо выключения.

Вентиляция резервных

Если включена настройка «Вентиляция у резервных», неактивные кондиционеры остаются включёнными в режиме вентиляции с заданной скоростью. Они не считаются работающими по правилам N и M. Когда резерв понадобится, контроллер переключит его в рабочий режим группы. Если настройка выключена, неактивные кондиционеры выключаются.

Ручное управление отдельным кондиционером

Флажок «Ручное управление» доступен для кондиционеров в автоматической группе. Пока он включён, контроллер не меняет настройки этого кондиционера и позволяет управлять им с карточки. Если кондиционер включён, он занимает слот M, но не засчитывается в N. После снятия флажка кондиционер снова подчиняется группе.

Минимальное время работы и простоя защищает от слишком частых переключений, а проверка запуска помогает убедиться, что выбранный кондиционер ответил на команду.

JSON и MQTT

/json — снимок состояния устройства в формате JSON. Ссылка требует входа и открывается отдельно.

MQTT, если включён в Settings, только публикует данные: fl_energy/<ID устройства>/state — состояние, /event — событие, /status — доступность. Команды через MQTT устройство не принимает. Префикс темы можно изменить в Settings.
